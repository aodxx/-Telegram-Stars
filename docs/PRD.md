# PRD — Telegram Stars Membership Bot

**สถานะเอกสาร:** Draft v0.1  
**วันที่:** 2026-09-30

## 1. วิสัยทัศน์

สร้าง Bot สมาชิก Telegram ที่ทำให้ผู้ดูแลสามารถเปิดระบบสมาชิกแบบรายเดือน โดยสมาชิกสามารถสมัคร ชำระเงิน ตรวจสอบสถานะ และต่ออายุได้จาก Telegram โดยไม่ต้องให้แอดมินทำงานด้วยมือในขั้นตอนปกติ

## 2. ขอบเขต MVP

### สมาชิก
1. /start
2. ดูข้อมูลบริการ
3. สมัครสมาชิก 30 วัน
4. ชำระด้วย Telegram Stars
5. ดูวันหมดอายุ
6. รับลิงก์/สิทธิ์เข้ากลุ่ม
7. รับการแจ้งเตือนก่อนหมดอายุ
8. ต่ออายุ
9. /paysupport สำหรับปัญหาการชำระเงิน

### ระบบ
1. ตรวจสอบ successful payment
2. เก็บ Telegram payment charge ID
3. บันทึกสมาชิก
4. คำนวณวันหมดอายุ
5. ตรวจสมาชิกหมดอายุ
6. จัดการสิทธิ์สมาชิกใน Group
7. บันทึก log

### Admin ระยะถัดไป
- Dashboard
- รายชื่อสมาชิก
- รายได้/ธุรกรรม
- การคืนเงิน
- ตั้งราคา
- ตั้งข้อความประชาสัมพันธ์
- Log และ audit

## 3. รูปแบบสมาชิก

เริ่มต้นเพียงแผนเดียว:

**Monthly — 30 วัน**

ราคา: **TBD Stars**

ราคาไม่ hard-code ใน UI และควรเก็บใน SETTINGS เพื่อให้เปลี่ยนได้โดยไม่แก้โค้ด

## 4. หลักการ UX

- ผู้ใช้ใหม่ต้องเข้าใจได้ภายใน 1 หน้าจอ
- ปุ่มหลักมีเพียง 1 action ที่เด่นที่สุด
- ทุกขั้นตอนต้องมีปุ่มย้อนกลับ
- หลังจ่ายเงินต้องแสดงผลสำเร็จ/ล้มเหลวอย่างชัดเจน
- ห้ามแสดงสถานะว่า “ชำระสำเร็จ” จาก client-side เพียงอย่างเดียว ต้องยืนยันจาก Telegram payment update
- เก็บข้อความ error ที่อ่านง่ายสำหรับผู้ใช้ และรายละเอียดทางเทคนิคไว้ใน log

## 5. สิ่งที่ยังไม่รวมใน MVP

- หลายระดับสมาชิก
- Referral
- Coupon
- Website dashboard เต็มรูปแบบ
- Mobile app แยก
- VPS
- Database server แยก

## 6. กฎด้านสิทธิ์เนื้อหา

ระบบสมาชิกนี้ควรใช้กับเนื้อหา/บริการที่ผู้ดูแลมีสิทธิ์เผยแพร่หรือให้สมาชิกเข้าถึงอย่างถูกต้อง
