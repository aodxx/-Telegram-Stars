# UI/UX Design — Telegram Stars Membership Bot

**Version:** 0.1  
**Status:** Design baseline

## 1. Design Direction

แนวทางภาพรวม: **Premium / Dark / Simple**

เพราะ Bot ใช้งานใน Telegram และผู้ใช้ควรตัดสินใจได้เร็ว หน้าจอจึงใช้ข้อความสั้น การ์ดข้อมูล และปุ่ม Inline Keyboard

### Visual language

- พื้นหลัง: ใช้ธีม Telegram ของผู้ใช้ ไม่บังคับสีพื้นหลังหนักเกินไป
- Accent: สีทอง/เหลืองใช้สื่อถึง Stars และการชำระเงิน
- Success: สีเขียว
- Warning: สีส้ม
- Error: สีแดง
- Typography: ใช้ข้อความสั้น อ่านง่ายบนมือถือ
- Emoji: ใช้เป็น visual cue แต่ไม่ใช้มากจนรก

## 12. UX Rules

- ห้ามให้ผู้ใช้ต้องพิมพ์คำสั่งเพื่อทำงานหลัก
- ใช้ Inline Keyboard เป็นหลัก
- ทุกหน้ามี Back
- Payment status ต้องมาจาก server-side verification
- ปุ่มเข้ากลุ่มต้องแสดงเมื่อระบบยืนยันสิทธิ์แล้ว
- ถ้าสมาชิกหมดอายุ ให้เปลี่ยน CTA เป็น “สมัครสมาชิก/ต่ออายุ”
